# ADR-004: Simulate before application

## Context
A schema-valid correction can still create a compliance or overtime problem when combined with the rest of the timecard.

## Decision
Apply each candidate to copied in-memory records and rerun the rules engine in V-07. Constrain actions and targets; do not edit breaks or reduce hours as a model instruction. Reject new high-severity findings and schedule edits below the configured minimum.

## Consequences
Unsafe side effects are caught before manager review, without writing during validation. The prompt instruction is backed by action constraints and simulation, not treated as enforcement by itself.
