# ADR-001: Deterministic detection; LLM-only proposals

## Context
Detection and correction application affect pay records and must be reproducible.

## Decision
Rules, constraints, validation, simulation, and application stay in deterministic code. The LLM may explain and propose only within retrieved evidence and case constraints.

## Consequences
Critical outcomes are testable and model faults cannot directly write timekeeping data. The model improves explanation quality, not detection authority.
