# ADR-006: SQLite hash-chained audit log

## Context
Managers need a traceable account of prompt, provider, validation, fallback, and decision events.

## Decision
Append canonical JSON events to SQLite and hash each event with the previous global hash and its identifying fields. Add triggers that reject ordinary updates and deletes, plus a verifier that recomputes the chain.

## Consequences
The demo is self-contained and audit changes are detectable in normal use. A privileged actor who can replace the database and recompute the entire chain is not prevented without an external trust anchor.
